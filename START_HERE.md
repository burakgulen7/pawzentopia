# PawZenTopia website handoff

This folder is a complete design and implementation handoff for Claude Code Web.

## What the user should do

1. Download and unzip this package.
2. Upload the entire unzipped folder—or the ZIP if the session accepts it—to a new Claude Code Web session.
3. Send this message:

> Bu paketteki `CLAUDE.md` ve diğer bütün talimatları okuyarak PawZenTopia web sitesini kur. Onaylı masaüstü ve mobil tasarıma 1:1 sadık kal. Önce dosyaları incele, sonra eksik işletme bilgileriyle domain/hosting tercihlerini bana toplu şekilde sor ve aşamalar halinde ilerle. Önizleme onayımı almadan canlıya alma veya domain/DNS değişikliği yapma.

Claude Code should then follow `CLAUDE.md` automatically. If it starts proposing a new design, remind it that `reference/desktop-approved.png` and `reference/mobile-approved.png` are binding visual references.

## Package map

- `CLAUDE.md`: binding build and deployment workflow.
- `DESIGN_SPEC.md`: precise layout, color and responsive rules.
- `CONTENT_FR.md`: approved draft French copy and content caveats.
- `QUESTIONS_AND_DEPLOYMENT.md`: questions Claude must ask before launch.
- `assets/brand/`: original company logo.
- `assets/photos/`: approved generated photographs.
- `reference/desktop-approved.png`: approved desktop composition.
- `reference/mobile-approved.png`: approved mobile composition.
- `reference/design-reference.html`: static implementation reference.
- `MANIFEST.sha256`: integrity list for all delivered files.

## Important

The approved photographs are synthetic marketing visuals derived from supplied references. The business owner should confirm that her likeness and each dog’s appearance are acceptable before publication.
